# QuickBite 🍔

A responsive food ordering web application built as a practice project to develop practical web development skills.

## 📌 Project Overview

QuickBite is a simple food ordering website that allows users to browse food items, search and filter the menu, add items to an order, adjust quantities, and complete a frontend checkout process.

The project focuses on practicing HTML, CSS, JavaScript, responsive design, DOM manipulation, and browser local storage.

## ✨ Features

- Responsive food ordering interface
- Food menu browsing
- Search functionality
- Category filtering
- Add items to order
- Increase and decrease quantities
- Remove items from order
- Order total calculation
- LocalStorage order persistence
- Checkout form
- Order confirmation
- Generated order ID
- Printable receipt
- Mobile-friendly navigation
- Accessible form and interface elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Tablet
- Mobile devices
